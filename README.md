# INDIA CPI-INFLATION-Data-Analysis (Interactive Dashboard Creation using MS Excel)
## Project Objective
This project analyzes India's Consumer Price Index (CPI) data to uncover inflation trends, category-wise contributions, food inflation drivers, and the impact of COVID-19 on key sectors. Using Microsoft Excel, the project applies data cleaning, inflation calculations, pivot tables, and dashboard development techniques to transform raw CPI data into actionable insights.
